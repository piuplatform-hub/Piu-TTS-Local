# Architecture Decision Records (ADRs)

ADRs capture **why** a choice was made, not just what the code currently does. Canonical index: [DECISION_LOG.md](DECISION_LOG.md). Refer to [ADR_TEMPLATE](../templates/ADR_TEMPLATE.md) for new decisions.

All ADRs below are **proposed**, awaiting explicit Product Owner approval. The original Gemini R1 technical selection remains available in `../architecture/TECHNOLOGY_DECISIONS.md`.
