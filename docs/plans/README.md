# Plans

A plan defines a future permissioned scope, not work that has already happened. Each phase gets one proposed or approved plan with acceptance tests, and one dated report with evidence after execution.

- [Phase 1 — Foundation](PHASE_01_FOUNDATION.md) — **PROPOSED**, not authorized.
- Future Phase 1B model spike must have a separate approval gate and report in `../reports/benchmarks/`.

Use [`PLAN_TEMPLATE`](../templates/PLAN_TEMPLATE.md) for milestones and phase plans.
